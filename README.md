# BitextFolio

英語段落の直後に日本語訳の段落が続く対訳テキスト（または英語原文のみ＋都度日本語入力）を、人間が精読レビューする際のブラウザ完結型・英日対訳チェック支援ワークベンチです。

**ビルド工程なし・外部通信なし・AI/機械翻訳 API 不使用**で、決定的（deterministic）なルールによるヒント提示と進捗記録に特化しています。HTML / CSS / ネイティブ ES Modules のみで構成されているため、リポジトリをそのまま GitHub Pages へ公開して利用できます。

---

## 主な特徴

- **完全ブラウザ完結・外部送信ゼロ**
  - `fetch` / `XMLHttpRequest` / `WebSocket` / 外部 CDN / 外部 Web フォント / 解析タグを一切使用しません。
  - 厳格な Content Security Policy（`default-src 'self'; connect-src 'none'`）を設定しており、入力テキストが外部サーバーへ送信されることはありません。
- **柔軟な取り込みと構造警告**
  - ペーストまたは UTF-8 `.txt` / `.md` ファイルのドラッグ＆ドロップ読み込みに対応。
  - 空行区切りの「英語段落 → 日本語段落」交互形式に加え、**「英語原文のみ（後から段落ごとに日本語入力）」** モードにも対応しています。
  - 文字種比率による言語自動判定（手動入替可）、英語連続／日本語連続／末尾英語などの構成崩れ警告、ブロック結合、箇条書き（`-`, `*`, `・`, `1.`, `(1)` 等）の行分割に対応。
- **英日文分割と n:m 対応編集**
  - 英語は略語（`e.g.`, `i.e.`, `et al.`, `Fig.`, `No.`, `vs.`, `approx.`, `ver.` 等 — ユーザー編集可）、バージョン表記（`SP 800-61r3, ver. 2.0`）、小数点（`0.5%`）、引用符内終止で誤分割しない設計。
  - 日本語は句点直後の閉じ括弧（`」`, `』`, `）`, `)`）を直前の文に保持します。
  - 左右2列／上下2段の切替、文の分割（スライダー指定）・結合・ドラッグ＆ドロップ／ボタンによるグループ移動、「対応なし」枠への直接入力・コピペ反映に対応（1対多・多対1・省略／補足も表現可能）。
- **進捗記録・部分マーカ・差し替え再読込・バックアップ**
  - 文グループごとに「未読 / 読了 / 確認済 / 要確認 / 変更あり」とメモ、「訳漏れなし（一時記録）」フラグを保持し、IndexedDB に自動保存（複数ドキュメント管理可）。
  - 長文チェック時に英文・和文をドラッグ選択して `H` キー（または右クリック）から「選択範囲をマーカ」（既マーカ範囲なら解除）、`Shift+H` で「文頭〜選択末尾までをマーカ」ができ、文分割や結合を行ってもマーカ位置が引き継がれます。
  - 単一文書／全データの JSON エクスポート＆インポート、およびハッシュ照合による原文差し替え時の確認状態引き継ぎに対応。
  - キーボード操作（`h` 選択範囲マーカ切替、`Shift+h` 文頭〜末尾マーカ、`j`/`k` 移動、`v`/`Enter` 確認済、`r` 読了、`t` 訳漏れなし一時記録、`f` 要確認、`m` メモ、`?` 操作ガイド）対応。
- **用語集・表記ゆれ吸収・日→英逆引き**
  - 英語の規則活用形（複数形・`-ing`・`-ed`）＋手動活用形、大文字小文字区別オプション、日本語の表記ゆれ吸収（全角半角・カタカナ長音「ー」・送り仮名）に対応。
  - 非推奨訳語や許容訳語未出現のリアルタイムチェック、日→英逆引き検索＆該当箇所ジャンプ、UTF-8 CSV / TSV 入出力に対応。
- **文単位の翻訳メモリ (TM)・漏れ/混入ヒント・用語候補抽出**
  - 「確認済」にした対訳ペアを文字 3-gram インデックス付きで翻訳メモリに自動蓄積（TMX 1.4 エクスポート対応）し、類似英文に対する過去訳との差異を警告します。
  - 本文中の英文・和文をドラッグ選択して **右クリック** することで、その場から 1 クリックで翻訳メモリや用語集へ登録できます。
  - 数値・年号・バージョン・URL・CVE 識別子・大文字略語の漏れ／和文側への未知トークン混入／コピペ重複を決定的ルールで検知し、個別に「許容・非表示」（復元可）にできます。
  - 頻出英語 n-gram と同一枠内日本語の共起集計による用語候補抽出を搭載しています。

## GitHub Pages での公開手順（ビルド不要）

Node.js やビルドツールは不要です。Windows 等でファイルをそのまま push するだけで公開できます。

1. GitHub 上にリポジトリ（例: `BitextFolio`）を作成（またはフォーク）し、ファイル一式を `main` ブランチへ push します。
2. GitHub リポジトリページの **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選択します。
4. **Branch** に `main`（または公開ブランチ）、フォルダに **`/ (root)`** を指定して **Save** をクリックします。
5. 公開 URL（`https://<ユーザー名>.github.io/BitextFolio/` ※リポジトリ名部分は大文字・小文字を含め実際のリポジトリ名に一致します）にアクセスすると即座に動作します。

> **補足**: ルートの `.nojekyll` ファイルにより GitHub Pages 側の Jekyll 変換を無効化し、ES Modules をそのまま配信します。

## ファイル構成

```text
.
├── index.html               # エントリHTML（厳格なCSP設定・相対パス読込）

├── styles/
│   └── app.css              # ライト／ダーク対応スタイルシート
├── js/
│   ├── main.js              # アプリ初期化・キーボードショートカット
│   ├── core/                # DOM非依存の決定的ロジック群（単体テスト対象）
│   │   ├── alignment.js     # n:m グループ管理・DP補助整列・分割/結合/移動
│   │   ├── block-parser.js  # 空行分割・仮ペア構築・英語原文のみ読込
│   │   ├── document-builder.js # 文書生成・統計集計・空枠直接入力反映
│   │   ├── glossary.js      # 用語照合・英語屈折・日本語正規化・CSV/TSV
│   │   ├── hash-diff.js     # 原文差し替え時のハッシュ比較・進捗引継
│   │   ├── hints.js         # 数値/URL/略語漏れ・混入・コピペ重複検知
│   │   ├── lang-classifier.js # 文字種比率による英日判定
│   │   ├── markers.js       # 長文マーカ範囲の正規化・分割/結合追従・トークン分割

│   │   ├── sentence-splitter.js # 英日文分割・箇条書き行分割
│   │   └── tm.js            # 文字n-gram翻訳メモリ・TMX出力・共起用語抽出
│   ├── state/

│   ├── storage/
│   │   ├── indexed-db.js    # IndexedDB永続化（localStorageフォールバック付）
│   │   └── json-io.js       # JSON / CSV / TSV / TMX ファイル入出力
│   └── ui/
│       ├── modals.js        # 原文読込・JSON管理・用語集・TM・設定モーダル
│       ├── render-helpers.js # 安全なDOM生成（innerHTML不使用）・フィルタ判定
│       └── workspace.js     # 2列/上下表示・仮想スクロール・D&D・右クリック登録
├── tests/
│   └── core.test.js         # Node.js 標準テストランナー用単体テスト
└── package.json             # 開発用ローカルサーバー・型チェック・テスト用設定（公開時は不要）
```

## 開発・テスト用コマンド（任意）

公開自体には不要ですが、ロジック変更後の回帰テストやローカル確認を行う場合は Node.js 20+ を利用できます。

```bash
# 単体テストの実行（DOM非依存コアモジュール 19件）
node --test tests/core.test.js

# 初回のみ開発用ツールを入れる場合
npm install

# ローカル確認サーバー起動（http://localhost:3000）
npm run dev

# 型・構文チェック
npm run lint
```

> 注意: ローカル確認時にブラウザの `file://` プロトコルで直接 `index.html` を開くとブラウザの CORS 制約により ES Modules が読み込まれません。ローカルで確認する場合は `npm run dev` または `python -m http.server` 等のローカル HTTP サーバー、あるいは GitHub Pages 上で開いてください。
